# MagSafeCrest

## Introduction
This is a custom, ergonomic, stackable, MagSafe grip for iPhone.  

## Impetus
Why did I make this?  
I made this grip because I could not find anything like it for sale, and similar products (like the PopSocket) had issues that bothered me.
